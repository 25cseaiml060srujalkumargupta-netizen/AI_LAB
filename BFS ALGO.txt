BFS
1-CREATE AN EMPTY LIST CALLED VISETED
2-CREATE AN EMPTY LIST CALLED AS QUEUE.
3-PUT START-NODE INTO THE QUEUE.
4-MARK THE START-NODE AS VISITED.
  4.1-WHILE THE QUEUE IS NOT EMPTY DO: CURRENT NODE = POP FROM THE QUEUE.PRINT THE CURRENT NODE
  FOR EACH NEIGHBOUR CONNECTED TO CURRENT-NODE:
      IF NEIGHBOUR IS NOT VISITED:
         ADD NEIGHBOUR TO VISITED
         ADD NEIGHBOUR TO THE BACK OF THE QUEUE.
5-EMPTY QUEUE IS REACHED.
